# 🎯 OPERATIONAL SECURITY (OPSEC) GUIDE: Захист від BDA

## 1. Правило Протидії Оцінці Бойових Збитків (Anti-BDA)
- Ворог веде постійний моніторинг відкритих Telegram-каналів та веб-мап для коригування повторних ударів.
- Заборонено публікацію у цивільному контурі точних адрес уражених військових об’єктів та підстанцій.
- Події наслідків атак на землі санітизуються: публікується лише район міста, без зазначення номерів цехів, складів чи критичних технологічних ліній.

## 2. Відкрита Кінематика в Повітрі
- Координати, швидкість та курс «Шахедів» у повітрі транслюються для цивільного населення в режимі 1:1 без штучного розмиття.
- Це рятує життя цивільних та дає можливість своєчасно сховатися в укриття.
- Але специфічні розширення (куди саме націлений дрон, які підстанції знаходяться у конусі його польоту) надійно сховані за 24-годинним доступом Security Officer.
